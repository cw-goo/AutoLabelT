# 视频批量处理与目标张数

在右侧“视频数据集”面板点击“添加视频（可多选）”，添加素材，用“上移”“下移”“移除”管理队列。队列按显示顺序依次处理，整批复用一个检测模型，输出合并到同一数据集。

侧栏依次排列“素材队列、检测模型、采样计划、构建与复核”四个模块。窗口高度不足时，可以滚动查看模块，底部的“开始训练”按钮始终可见。长路径、参数摘要及预分析说明可悬停查看完整内容。“数据集图片数量”指输出目录期望达到的图片总数，0 表示按动态步长扫描。

四个圆角模块共同填满标题与训练按钮之间的区域，新增空间优先分给素材队列和运行记录。构建时进度条实时显示整批进展，运行记录保留每段视频的开始、完成、补采和错误等节点。“模型加载”按钮位于检测模型模块正中；图片模型使用左侧图片标注入口。模型广场目前仅提供 IDEA-Research 的 Grounding DINO Tiny/Base 和 Meta 的 SAM 3/3.1，右侧显示所选模型的任务、权重状态、来源、许可证及类别要求，选择模型本身不触发下载。

## 按目标生成

1. 添加视频，准备检测模型和类别。
2. 点击“预分析并推荐”。在“采样计划”底部的结果框内滚动查看各视频的分配张数和初始间隔。将光标停在摘要或视频行上可查看目标数量分布及合格率。调整张数或帧间隔时会用已有抽检结果重算。
3. 打开“调整参数”，检查或修改回填的步长和其他处理参数，点击“使用参数”确认。再次调整张数、间隔或重新预分析后，需要确认新的参数。
4. 选择输出目录，点击“开始构建”。如果确认的检测或筛选设置和预分析时不同，构建前会用确认后的设置重新抽检。

预分析读取视频元信息，并在整条时间轴上分散抽检，每个视频最多进行 80 次模型推理。目标分布按抽检比例估算，抽检合格率另按画面筛选条件计算。预分析可以在设置目标张数及输出目录前执行，期间不写入数据集。换模型、修改检测设置或完成构建后，可以用现有队列再次预分析。下载的临时权重可重复使用，关闭软件时统一清理。配置兼容旧版本 JSON。

正式处理按可用内容估算量分配额度，为不同视频及不同时间段保留样本。实际合格率决定后续补采密度；某段内容不足时，剩余额度可转移到其他时间段或视频。首轮按队列顺序处理，必要时回到前面的视频补采。已推理位置不会在同一批的正式处理与补采中重复推理。

目标模式用推荐的初始间隔设定首轮采样密度，后续按实际合格率调整。预分析也会在“调整参数”中回填空镜、单目标、2–3 目标和 4+ 目标的动态步长，供不限张数时直接使用。不限张数时按视频帧率换算基准步长，合格帧较少时会缩短步长。手动应用的步长会保留到下次主动预分析，两种模式共用置信度、目标高度及小目标占比等质量条件。

## 数量与质量

素材充足时尽量达到目标，最多保存目标张数；素材不足时显示实际数量和缺口，保持既定质量门槛。估计结果依赖少量抽检，补采可能延长耗时。网格采样可能漏掉间隙中的短暂事件。

目标模式默认在同一视频的两张保存图片之间保留至少 25 帧。界面加载旧的秒数配置时，按队列第一段视频的帧率换算。人工复核删除图片后，最终张数也会减少。

## 完整扫描与输出

“数据集图片数量”设置为 `0` 表示完整扫描，按动态步长和质量规则筛选整段视频。预分析会把步长填入“调整参数”，可手动修改，点击“使用参数”后生效。单视频完整扫描保留原有文件命名；批量及目标模式的文件名包含完整视频名与路径摘要，区分同名文件和同一摄像头的多个片段。

图片、YOLO 标签和复核标注仍位于 `images/`、`labels/`，源视频和帧号记录在 `metadata/samples.jsonl`，批量统计另存为 `metadata/batch_*.json`。在同一目录继续构建时，已有图片计入目标总数，软件会避开已有样本并补齐剩余张数。已有类别表与新提示类别需要一致。若想从头生成一套数据，使用当前队列并选择新的输出目录即可。取消任务会保留已生成的样本。
