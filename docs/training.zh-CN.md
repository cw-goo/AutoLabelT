# 可视化训练中心

运行 `autolabelt`，点击右侧边栏底部“开始训练”。折叠按钮位于边栏内部，折叠后保留展开入口。训练窗口独立显示，关闭窗口会隐藏界面，训练继续。退出整个应用会停止后台任务。

## 准备数据

- 人工调整标注后，先在数据集面板点击“同步更新标签”。软件保存当前画布，并把复核 JSON 写回用于训练的原 YOLO TXT。
- 选择包含 `images/` 和 `labels/` 的数据集目录及“保存位置”。类别来自 `classes.txt`，已划分的目录也可以用同目录的 `data.yaml` 提供类别。在 YAML 一行可点击“浏览”指定已有配置，或设置训练比例后点击“生成”。
- 已有 YAML 保留 train/val 划分，支持图片目录、目录列表和图片清单 TXT。相对清单路径按清单所在目录解析。
- 普通目录自动划分数据；`视频名_f帧号` 样本按来源分组，单视频按时间顺序划分。独立视频验证更能反映实际效果。
- 缺失标签、非法类别、非法框、不可读图片和 train/val 重复路径会阻止训练。负样本须有空 TXT。

“生成”会把 `data.yaml` 保存到“保存位置”，并在该位置下保存划分目录，目录包含 `images/train`、`images/val` 和对应的标签。已有划分时沿用其分组，数据已在保存位置内时直接引用。再次生成会更新 `data.yaml`。如果之后同步了源标签，可以重新生成，或留空 YAML 路径直接用源目录训练。

点击“开始训练”时，任务目录中的 `data.yaml` 直接引用已经划分好的图片和标签目录。仅提供未划分的源目录时，软件会先生成划分。当前窗口内再次使用同一批图片训练时，软件复用已有划分并刷新修改过的标签。历史 TXT 图片清单仍可导入，准备训练时会整理为目录式数据集。

## 选择模型与环境

支持 YOLO 和 RT-DETR 的目标检测训练，可选择内置型号或本地 `.pt` 权重，也可输入兼容的模型 YAML。RT-DETR 图片尺寸至少为 256。基础参数默认采用 150 轮、图像尺寸 1024、批量 24、设备 1。GPU 从 0 编号，设备 1 是第二张显卡。也可选择 `auto`、`cpu` 或其他 GPU 编号。

基础参数同行的“高级设置”将选项分为数据加载、迁移训练、训练控制、数据增强和性能设置。输入框旁有常用范围。默认使用 8 个加载进程、RAM 缓存、AdamW、混合精度，关闭确定性训练。随机擦除是 Ultralytics 的图像分类增强参数。默认使用应用当前的 Python 环境，使用其他虚拟环境时可在弹窗修改“Python 环境”。该环境需已安装兼容的 PyTorch、Ultralytics 和训练依赖。训练运行在独立子进程中。

## 实时监控与训练结果

实时显示当前轮次、设备、GPU 保留显存（CUDA）、耗时和估算剩余时间。损失曲线以实线显示训练值、虚线显示验证值。Precision、Recall 和 mAP 以百分比显示。曲线在每轮验证后展开新线段，点击图例可切换曲线，悬停可读取该轮的数值。实时日志同步显示训练和验证进度。

任务目录包含 `task.json`、`training.log`、`data.yaml`、样本清单和 `train/` 下的训练输出。样本清单记录每张图片的划分、实际读取路径及标签 SHA-256。训练记录显示数据集和模型简称，第二行显示创建时间和状态，完整路径可在悬停时查看。

结果页显示 `best.pt`、`last.pt` 的生成情况和最新指标。点击“格式转换”打开弹窗，可以转换当前任务的 `best.pt` 或导入本地 `.pt`。选定 ONNX 保存路径后自动转换，弹窗显示动态进度条，完成时填满。任务转换使用记录中的 Python 环境及图像尺寸，导出路径附在该任务结果页。本地转换使用高级设置中的 Python 环境，输入尺寸由权重决定。

“停止训练”终止训练进程并保留已有文件。重新训练时直接点击“开始训练”，软件会使用当前设置新建任务并沿用选定的数据划分。

## 验证

`tests/test_training_center.py` 覆盖数据划分复用、标签清单、无效标签、划分重叠、结构化训练事件和本地 PT 转换入口。YOLO 与 RT-DETR 已通过小数据集单轮 CPU 训练验证。在 Windows 上还用 RTX A2000 完成了 YOLO 单轮 CUDA 训练，并通过训练中心导出了经校验的 ONNX。
