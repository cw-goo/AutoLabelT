AutoLabelT for Linux
====================

Requirements: a graphical Linux desktop, Python 3.11 with venv and pip,
internet access during installation, and enough disk space for PyTorch,
Qt, and other dependencies. Package availability depends on CPU
architecture and Linux distribution. No root privileges are needed.

1. Extract the complete archive:
   tar -xzf AutoLabelT-0.1.0-Linux.tar.gz
2. Enter the extracted AutoLabelT-* directory.
3. Run: bash install.sh
4. Start with autolabelt. If ~/.local/bin is outside your PATH, run
   ~/.local/bin/autolabelt directly.

To choose a Python executable or install directory, set environment
variables before running the script, for example:
  PYTHON=/path/to/python3.11 AUTOLABELT_INSTALL_DIR="$HOME/Apps/AutoLabelT" bash install.sh

The installer uses a private virtual environment and downloads Linux
dependencies on the target computer. For NVIDIA CUDA or AMD ROCm, install
the appropriate PyTorch build into that environment using the command from
https://pytorch.org/get-started/locally/ for the target device.

Image annotation can run without a detection model. Video detection needs
a compatible local YOLO .pt model selected in the video panel; weights and
datasets are not included. A graphical session is required for the UI.

To uninstall, remove the installation directory and ~/.local/bin/autolabelt.
Annotation datasets and ~/.autolabeltrc are stored separately. The bundled X-AnyLabeling code is
licensed under GPL-3.0; see LICENSE and THIRD_PARTY_NOTICES.md.
